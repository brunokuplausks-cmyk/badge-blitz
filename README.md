# Badge Blitz — Football Quiz

A small static football-badge quiz for GitHub Pages.

## Files

- `index.html` — the quiz website.
- PNG files — the badge artwork used by the quiz. Keep them in the same folder as `index.html`.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public repository named `badge-blitz`.
2. Upload **all files in this folder** to the repository root (do not put the PNGs in a subfolder).
3. Commit the upload to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. After deployment, open `https://YOUR-USERNAME.github.io/badge-blitz/` and replace `YOUR-USERNAME` with your GitHub username.

The quiz includes 59 clubs and 12 national teams, all with matching PNG image files in this package.
